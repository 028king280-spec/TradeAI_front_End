## 3. Timezone & Conversion Logic Audit

### Backend & Application Logic (`backend/app/data/market_calendar.py`):
```python
IST_ZONE = zoneinfo.ZoneInfo("Asia/Kolkata")

class MarketCalendar:
    @staticmethod
    def now_ist() -> datetime:
        return datetime.now(IST_ZONE)

    @classmethod
    def format_ist_timestamp(cls, dt: datetime = None) -> str:
        if dt is None:
            dt = cls.now_ist()
        return dt.strftime("%d %b %Y, %I:%M %p IST")
```
- **Timezone:** Strictly enforced as `Asia/Kolkata` (UTC+05:30).
- **Format String:** `%d %b %Y, %I:%M %p IST`.
- **Limitation:** The format string truncates seconds and milliseconds. Because `now_ist` was invoked within the same wall-clock minute on 05 Nov 2026 at 22:32 IST, all entry and exit timestamps became identical text strings.
